# 음성 넣는 법 (일레븐랩스)

아이는 글을 못 읽으므로 안내는 전부 음성이다. 이 폴더의 `<키>.mp3`가 재생되고, 파일이 없는 문장은 아이폰 내장 한국어 음성이 대신 읽는다.

지금 들어 있는 37개는 일레븐랩스 API로 만든 것이다.

- 목소리: Kelee K (`5DWGv3VDkihNUcbvaonB`, 한국어 여성) — **모든 문장을 같은 목소리로**
- 모델: `eleven_v3`, `language_code: ko`, 대본 앞에 `[cheerfully] ` 태그, stability 0.5, `mp3_44100_128`
- 다시 만들 때: `POST https://api.elevenlabs.io/v1/text-to-speech/<voice_id>` (키는 환경에 저장되어 있어 자동으로 붙는다)

놀이 시작 안내는 파일명이 놀이 id와 같다(`bubble.mp3` = 비눗방울 팡 시작).
대본을 바꾸면 `js/audio.js`의 `VOICE`도 같이 고친다(파일이 없을 때 읽는 문장).

짧은 단어는 eleven_v3가 뭉개기 쉽다. 만든 뒤 speech-to-text로 다시 받아써서 확인할 것.
"까꿍!"은 `[excited]` 태그로, "무궁화 꽃에 도착"은 "무궁화호 채"로 들려서 "꽃까지 왔어요"로 바꿨다. "골인!"은 끝까지 "꼬린"으로 들려서 "슛! 골인!"으로 바꿨다.

`mugung.mp3`(무궁화 꽃이 피었습니다)는 놀이가 매번 빠르기를 0.8~1.3배로 바꿔 튼다(술래가 빨리/천천히 말하는 재미).
