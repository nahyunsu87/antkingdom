# 음성 넣는 법 (일레븐랩스)

아이는 글을 못 읽으므로 안내는 전부 음성이다. 아래 파일명으로 이 폴더에 mp3를 넣으면 자동으로 쓰인다.
파일이 없는 문장은 아이폰 내장 한국어 음성이 대신 읽는다(기계음이라 어색함).

- 목소리: 한국어 여성, 밝고 다정한 유치원 선생님 톤. **12개 모두 같은 목소리**로
- 모델: Eleven v3 또는 Multilingual v2 (한국어 지원 모델)
- 형식: mp3, 앞뒤 무음은 짧게

| 파일명 | 대본 | 나오는 때 |
|---|---|---|
| `hello.mp3` | 안녕! 우리 같이 놀자! | 시작 버튼을 눌렀을 때 |
| `menu.mp3` | 하고 싶은 놀이를 골라 봐요! | 놀이 고르는 화면 |
| `bubble.mp3` | 비눗방울을 손으로 팡! 터뜨려 봐요! | 비눗방울 놀이 시작 |
| `catch.mp3` | 하늘에서 별이 떨어져요! 별을 잡아 봐요! | 별 받기 시작 |
| `ant.mp3` | 개미가 집에 가고 싶대요! 신나게 뛰어 봐요! | 개미 달리기 시작 |
| `copy.mp3` | 그림을 보고 똑같이 따라 해 봐요! | 따라 해봐 시작 |
| `pose_up.mp3` | 두 손 번쩍, 만세! | 따라 해봐: 만세 |
| `pose_small.mp3` | 개구리처럼 작게 앉아 봐요! | 따라 해봐: 웅크리기 |
| `pose_wide.mp3` | 비행기처럼 팔을 쭉 벌려 봐요! | 따라 해봐: 팔 벌리기 |
| `arrive.mp3` | 도착! 한 번 더! | 개미가 집에 도착 |
| `lost.mp3` | 어디 갔지? 카메라 앞으로 와요! | 아이가 화면 밖으로 나감 |
| `done.mp3` | 참 잘했어요! 정말 멋져요! | 놀이가 끝남 |

대본을 바꾸면 `js/audio.js`의 `VOICE`도 같이 고친다(파일이 없을 때 읽는 문장).
