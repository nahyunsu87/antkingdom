# 그림 넣는 법 (제미나이)

그림이 없어도 놀이는 이모지로 돌아간다. 아래 파일명으로 이 폴더에 PNG를 넣으면 자동으로 교체된다.
음성은 `voice/README.md` 참고.

| 파일명 | 쓰이는 곳 | 지금 대체 이모지 |
|---|---|---|
| `bubble.png` | 비눗방울 | 🫧 |
| `star.png` | 떨어지는 별 | ⭐ |
| `ant.png` | 달리는 개미 (오른쪽을 보는 옆모습) | 🐜 |
| `home.png` | 개미집 | 🏠 |
| `pose_up.png` | 만세 하는 개미 | 🙌 |
| `pose_small.png` | 개구리처럼 웅크린 개미 | 🐸 |
| `pose_wide.png` | 양팔을 옆으로 쭉 벌린 개미 | ✈️ |
| `icon_bubble.png`, `icon_catch.png`, `icon_ant.png`, `icon_copy.png` | 놀이 고르는 카드 | 🫧 ⭐ 🐜 🙌 |

`pose_*.png` 세 장이 가장 중요하다. 아이가 이 그림을 보고 동작을 따라 하므로, 팔다리 모양이 한눈에 보이는 정면 전신이어야 한다.

## 규칙

- 정사각형, 512×512 이상, 그림은 가운데에 꽉 차게, 글자 없이
- **배경은 단색 초록(#00FF00)** 으로 요청한다. 제미나이는 투명 배경을 못 만들고 "투명"을 요청하면 체크무늬를 그려 넣는다.
  네 귀퉁이가 같은 단색이면 게임이 그 색을 알아서 투명하게 지운다. (그래서 그림 자체에는 초록색을 쓰지 말 것)
- 한 대화창에서 연달아 생성해야 화풍이 맞는다

## 프롬프트 예시

첫 장에서 화풍을 고정한다:

> 유아용 운동 놀이에 쓸 귀여운 개미 캐릭터 그림을 여러 장 그릴 거야. 두꺼운 외곽선, 납작한 색면, 밝은 원색, 스티커 느낌, 큰 눈.
> 배경은 아무 무늬 없는 순수한 초록색(#00FF00) 단색, 그림자 없음, 글자 없음, 정사각형.
> 첫 번째: 개미가 정면을 보고 서서 두 팔을 머리 위로 번쩍 들어 만세 하는 전신.

이후 같은 대화에서 "같은 캐릭터, 같은 화풍, 같은 초록 배경: ○○" 만 바꿔 요청한다.
