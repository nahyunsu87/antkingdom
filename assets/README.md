# 그림 넣는 법 (제미나이)

그림이 없어도 게임은 이모지로 돌아간다. 아래 파일명으로 이 폴더에 PNG를 넣으면 자동으로 교체된다.

| 파일명 | 쓰이는 곳 | 지금 대체 이모지 |
|---|---|---|
| `target.png` | 펀치 표적 | 🎯 |
| `bomb.png` | 펀치 폭탄 | 💣 |
| `star.png` | 별 받기 별 | ⭐ |
| `rock.png` | 별 받기 돌 | 🪨 |
| `runner_p1.png`, `runner_p2.png` | 달리기 주자 (빨강/파랑) | 🐜 |
| `flag.png` | 달리기 결승선 | 🏁 |
| `icon_punch.png`, `icon_squat.png`, `icon_run.png`, `icon_catch.png` | 메뉴 카드 | 🥊 🦵 🏃 ⭐ |

## 규칙

- 정사각형, 512×512 이상, 그림은 가운데에 꽉 차게
- **배경은 단색 초록(#00FF00)** 으로 요청한다. 제미나이는 투명 배경을 못 만들고 "투명"을 요청하면 체크무늬를 그려 넣는다.
  네 귀퉁이가 같은 단색이면 게임이 그 색을 알아서 투명하게 지운다. (그래서 그림 자체에는 초록색을 쓰지 말 것)
- 한 대화창에서 연달아 생성해야 화풍이 맞는다

## 프롬프트 예시

첫 장에서 화풍을 고정한다:

> 귀여운 개미 캐릭터가 나오는 어린이 운동 게임의 아이콘을 그릴 거야. 두꺼운 외곽선, 납작한 색면, 밝은 원색, 스티커 느낌.
> 배경은 아무 무늬 없는 순수한 초록색(#00FF00) 단색, 그림자 없음, 글자 없음, 정사각형.
> 첫 번째: 빨간 머리띠를 한 개미가 오른쪽으로 달리는 옆모습.

이후 같은 대화에서 "같은 화풍으로, 같은 초록 배경: ○○" 만 바꿔 요청:

- 파란 머리띠를 한 개미가 오른쪽으로 달리는 옆모습 → `runner_p2.png`
- 과녁판 → `target.png` / 심지에 불붙은 둥근 폭탄 → `bomb.png`
- 웃는 얼굴의 노란 별 → `star.png` / 회색 바위 → `rock.png` / 체크무늬 결승 깃발 → `flag.png`
- 권투 글러브 낀 개미 / 스쿼트하는 개미 / 달리는 개미 / 별을 안은 개미 → `icon_*.png`
